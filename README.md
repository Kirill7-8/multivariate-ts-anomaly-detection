# multivariate-ts-anomaly-detection
Research and implementation of preprocessing methods and anomaly detection techniques for multivariate time series.

Целью работы является разработка программного пайплайна предобработки многомерных временных рядов и исследование влияния методов обработки и декомпозиции на эффективность обнаружения аномалий.
Для достижения поставленной цели в работе необходимо решить следующие задачи:
1. Провести анализ существующих методов предобработки многомерных временных рядов и подходов к обнаружению аномалий.
2. Исследовать особенности многомерных временных рядов и основные проблемы их предварительной обработки.
3. Разработать программный пайплайн для загрузки, обработки, преобразования и подготовки многомерных временных рядов к обнаружению аномалий.
4. Реализовать и интегрировать в пайплайн методы декомпозиции временных рядов, а также другие методы предобработки и извлечения признаков.
5. Подготовить размеченные наборы данных для проведения экспериментальных исследований.
6. Провести сравнительный анализ влияния различных методов предобработки и декомпозиции на качество обнаружения аномалий.
7. Оценить результаты экспериментов и сформулировать рекомендации по применению исследованных методов.
