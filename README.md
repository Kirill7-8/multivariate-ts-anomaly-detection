# Разработка и исследование способов предобработки данных в задаче детекции аномалий в многомерных временных рядах

Целью работы является разработка программного пайплайна предобработки многомерных временных рядов и исследование влияния методов обработки и декомпозиции на эффективность обнаружения аномалий.

Для достижения поставленной цели в работе необходимо решить следующие задачи:

1. Обзор научной литературы и существующих подходов к обнаружению аномалий в многомерных временных рядах.

2. Анализ и выбор методов предобработки данных. Рассмотрение методов нормализации, фильтрации, декомпозиции временных рядов, вейвлет-преобразования и методов извлечения признаков, включая ROCKET, MiniRocket и Catch22.

3. Изучение и подготовка экспериментальных данных. Анализ доступных наборов данных для обнаружения аномалий в многомерных временных рядах.

4. Разработка программного комплекса для предобработки данных. Реализация единого конвейера обработки многомерных временных рядов, включающего загрузку данных, обработку пропусков, нормализацию, декомпозицию, вейвлет-преобразование и извлечение признаков.

5. Реализация базовых методов обнаружения аномалий. Выбор и реализация алгоритмов обнаружения аномалий, используемых для оценки эффективности различных способов предобработки данных.

6. Подготовить размеченные наборы данных для проведения экспериментальных исследований.

7. Проведение экспериментального исследования. Сравнение результатов обнаружения аномалий при использовании различных методов предобработки и извлечения признаков. Оценка качества обнаружения с помощью выбранных метрик, анализ полученных результатов.

8. Формулирование выводов и подготовка результатов работы. Обобщение результатов экспериментов.
